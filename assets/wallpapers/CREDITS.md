Each file is the 3200px-wide rendition, wider than the device pixels of the
display the screenshots render on — `tools/shots.js` scales and centre-crops it
to the exact screen size, so nothing is ever upscaled.

Frost itself uses your own Windows desktop wallpaper. These are here only so the
screenshots have a desktop to sit on.
