Settings

Backdrop

Switching in or out of Glass needs a restart: Windows only lets an app choose a transparent window when it starts. Frost will offer to do it.

How far the glass backdrop is darkened behind text, on top of the tint. A clear tint over a bright wallpaper is unreadable without it; set it to 0 if you want the wallpaper completely untouched.

Shell

Detected on first run. Edit profiles in theme.json to add your own — shell path, args, cwd, env. Ctrl+Shift+1…9 opens the Nth profile; the ▾ button lists them all.

PowerShell and bash profiles also report their directory back to Frost each prompt, which is what puts dir · branch on the tab. cmd and WSL can't, so those tabs keep the profile name.

Terminal

An argv template — {file}, {line} and {column} are filled in as whole arguments, never through a shell. Leave empty to use the first editor found on PATH.

Faster, and draws box-drawing characters itself. It rasterises glyphs into a texture, so a line height above ~1.2 can soften them slightly; turn it off for the sharpest text, at the cost of speed.

Notifications

Only while Frost is in the background — inside the app the tab dot already tells you. Set the slider to Off to skip command timing.

Cursor

Files

All hot-reload on save. theme.css accepts any CSS — full control. Ctrl+Shift+P lists every command with the key it currently answers to.
